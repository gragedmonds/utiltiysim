# Viewer bridge

The prototype's Three.js viewer (`prototypes/town-lab`, by Astra) rendering towns generated by the `utilsim`
engine. `public/model.js` replaces the prototype's in-browser generator with an adapter that loads a
`utility-town/2.0` snapshot and keeps the same exports (`createTown`, `flows`, `demand`, `traceService`,
`monthlyReads`, `terrain`), so `scene.js` and `app.js` change only where the engine adds detail:

* terrain from the snapshot heightmap; utility geometry already offset (no z-shift);
* road widths per class; flat roofs for commercial buildings; elevated tanks, depots, hydrants, district regulators;
* the inspector's source chain comes from the traced path (real kV, transformer, conductor and pipe sizes);
* reads load on demand from the API when the snapshot is the light `viewer` profile.

```bash
cd web && npm install && npm start            # http://localhost:5175 shows the bundled 480-home Whitby town
uv run utilsim serve                          # engine API on :8010 (from the repo root)
# then open http://localhost:5175/?api=http://127.0.0.1:8010 to generate any seed/size through the engine
```

`public/data/snapshot.json.gz` is `examples/whitby-480-seed42` (regenerate with
`uv run utilsim gen --preset whitby_small --seed WHITBY-042 --out examples/whitby-480-seed42`).
