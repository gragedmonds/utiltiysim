Download **UtilityStudio** for your computer: Windows opens the `.exe`; macOS and Linux unzip the launcher first.
The `runtime-*` files are downloaded automatically by the launcher; you do not need to choose one yourself.

On the first launch, choose the storage folder and click **Open Utility Studio**. The first start downloads and verifies
the engine into that folder; later launches open Studio directly using the saved location. A missing drive or startup
problem returns to setup. The gear in Studio opens app settings, updates and **Quit Utility Studio**.
Download this launcher once to get the new startup behaviour; the engine updater does not replace your launcher.
Utility Studio opens in your browser: set up a simulation,
tweak any setting, run the year and read the results, all on this computer. Nothing is uploaded.

**Simulation files.** Export a simulation in Studio and import the file in Utility Studio on another computer: the same
town, homes, seed, settings, dates and every scenario on the year come across. Each file is named by three words,
such as `brave-otter-harbour.utilitysim.json`.

**Offline Command Center.** New simulations of every size use one workspace with combined work queues, Data,
Activity sequences and VEE scorecards. Apply changes during the year and save new revisions. Map is removed from
desktop navigation, including existing small-town simulations.

**Five-step setup.** Build from the ground up or match existing KPI history and targets using the local engine.
The wider layout and animated engine monitor make long runs easier to follow.

**Variable dependencies.** The information icon opens a searchable, draggable engine tree. Hover a connection for
its rule or calculation, conditions and source references; pin it open or inspect each link on a shared connector.
All explanations are bundled for offline use.

The launcher keeps the engine up to date: it starts the installed engine at once and downloads a newer signed release
in the background for the next start (or **Restart with the new version** on its page). The engine has a pinned
SHA-256 digest and Ed25519 signature verified by the launcher. These builds have no Apple
notarization or Windows publisher certificate, so the operating system may show an unidentified-publisher prompt.
Linux needs a desktop browser and glibc 2.35 or newer. Measured sizes are in each platform's manifest JSON.
